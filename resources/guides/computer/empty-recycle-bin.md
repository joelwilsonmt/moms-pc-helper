# Empty the Recycle Bin and clear temp files

This is one of the easiest ways to free up space. Files in the Recycle Bin are already "deleted" from your point of view — they're just sitting there taking up room until you empty it.

## Empty the Recycle Bin

1. Find the **Recycle Bin** icon on your desktop. It looks like a trash can.

2. Right-click it (press the right mouse button).

3. Click **Empty Recycle Bin**.

4. Windows will ask *"Are you sure you want to permanently delete these files?"* — click **Yes**.

Done! Those files are gone for good now.

## Clear temporary files (takes 2 more minutes)

Windows keeps a folder of temporary files — these are leftovers from installing programs, Windows updates, and everyday use. They're safe to delete.

1. Press the **Windows key** and the letter **R** at the same time. A small box appears.

2. Type `%temp%` and press **Enter**.

3. A folder opens full of files. Press **Ctrl + A** to select everything.

4. Press the **Delete** key. If Windows says some files can't be deleted because they're in use — that's fine. Click **Skip** and it will delete the rest.

5. Empty the Recycle Bin one more time to finish.

## You're done

Between the Recycle Bin and temp files, you've probably freed up several gigabytes. Nice work!
